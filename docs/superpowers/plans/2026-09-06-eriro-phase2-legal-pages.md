# Phase 2 — Legal Pages & Cookie-Consent Banner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the three remaining legal/info routes (`/imprint/`, `/privacy/`, `/cookies/`) and the sitewide cookie-consent banner that Phase 1 specified but never built.

**Architecture:** Same direct-composition shape as the homepage (`app/page.tsx`) — each route is its own `app/<slug>/page.tsx` importing a hand-written content file and composing typed section components directly, no generic renderer. Three new `Section` types join the existing `HeroSection`/`ImgSection`/etc. union in `lib/content.ts`. The cookie-consent banner is `vanilla-cookieconsent` (a real npm dependency, not hand-cloned), mounted once in `app/layout.tsx`, using the library's own stock default theme (the live site never customized it).

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, `vanilla-cookieconsent` v3.1.0, Vitest + Testing Library (unit), Playwright (e2e + visual regression).

**Spec:** `docs/superpowers/specs/2026-09-04-eriro-clone-design.md` §17 (this plan implements that section; also relies on §6's `Section`/`PageContent` shape as actually implemented in `lib/content.ts`, and §16.1/§16.2/§16.4's architecture rules).

## Global Constraints

- No `/en/` prefix anywhere — every route, nav link, and test URL is `/imprint/`, `/privacy/`, `/cookies/` (spec §16.1).
- No generic `SectionRenderer`/`Mask` dispatch — every page composes its section components directly by name (spec §16.4).
- Styling is Tailwind utility classes in JSX; the one exception here is `.legal-content`, a small scoped CSS file for the raw-HTML content these pages inject via `dangerouslySetInnerHTML` (spec §17.2 — same class of exception as the gallery's `nth-child` rules).
- Content is hand-written TypeScript object literals per page, sourced verbatim (typos included) from the crawled `docs/reference/pages/en__*.json` payloads — never live-fetched, never generated by a script (spec §16.2).
- No analytics/tracker scripts are loaded (spec §2) — the cookie-consent banner is real (spec §16.5 precedent: hand-integrate the real behaviour, don't load a vendor tracking script), but its own `onFirstConsent`/`onChange` Google-Consent-Mode callbacks from the captured source are **not** cloned.
- `npm run typecheck`, `npm test` (vitest), and `npm run build` must all stay clean after every task. This session's top-level Bash tool is blocked from running `npm run typecheck`/`npx vitest run` directly — route these through a subagent, per this project's own established workaround.

**Interfaces:**

- [ ] **Step 1: Write `tests/e2e/legal-pages-visual.spec.ts`**

```ts
import { test, expect, type Page } from '@playwright/test';

// These pages are plain typography with no scroll-linked animation, but they
// still render inside SmoothScroll's wrapper at desktop widths, and some (privacy
// especially, at ~20,000 characters of legal text) are far taller than any
// viewport -- the same stitching-under-ScrollSmoother hazard as img-visual.spec.ts,
// just for the whole page instead of one section. Same fix: grow the viewport's
// height to fit the whole `main` before capturing, then reposition deterministically.
async function jumpToTop(page: Page) {
  await page.waitForFunction(() => !!window.__scrollSmoother);
  const jump = () => page.evaluate(() => window.__scrollSmoother?.scrollTo('main', false, 'top top'));
  await jump();
  await page.waitForTimeout(300);
  await jump();
  await page.evaluate(() => new Promise((r) => requestAnimationFrame(() => requestAnimationFrame(r))));
}

const routes = [
  { path: '/imprint/', name: 'imprint' },
  { path: '/privacy/', name: 'privacy' },
  { path: '/cookies/', name: 'cookies' },
];
const viewports = [{ width: 1920, height: 951 }, { width: 1440, height: 900 }, { width: 390, height: 844 }];

test.describe('legal pages visual regression', () => {
  for (const { path, name } of routes) {
    for (const viewport of viewports) {
      test(`${name} matches at ${viewport.width}x${viewport.height}`, async ({ page }) => {
        await page.setViewportSize(viewport);
        await page.goto(path);
        const main = page.locator('main');
        const height = await main.evaluate((el) => el.getBoundingClientRect().height);
        if (height > viewport.height) {
          await page.setViewportSize({ width: viewport.width, height: Math.ceil(height) + 100 });
          await page.waitForTimeout(200); // SmoothScroll's resize handler is debounced 150ms
        }
        if (viewport.width >= 1024) {
          await jumpToTop(page);
        } else {
          await main.scrollIntoViewIfNeeded();
        }
        await page.waitForTimeout(500);
        await expect(main).toHaveScreenshot(`${name}-${viewport.width}.png`, { maxDiffPixels: 50 });
      });
    }
  }
});
```
