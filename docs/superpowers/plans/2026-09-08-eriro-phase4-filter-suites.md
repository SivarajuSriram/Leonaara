# Phase 4 — Filter/Suites Subsystem Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build 10 new routes — `/experiences/` (filter hub) + 5 subpages (`leiba`, `sela`, `herchomen`, `hantwerc`, `sneo`) + 4 suites (`/suites/{boum,wisa,felisa,himil}/`) — by adding 5 new `Section` types, one shared `FilterShell` component that drives both the experiences filter and the suites filter (identical mechanics, different data, per spec §9.15), 3 new content components (`RoomDetail`, `ImgSlider`, `RoomCta`), and composing all 10 pages directly by name.

**Architecture:** `FilterShell` owns the GSAP `ScrollTrigger` pin + client-side content-swap mechanics once, shared by both use cases — it takes a normalized item list, a same-length array of pre-rendered content nodes (one per item, all statically imported by the calling page, no fetch), and swaps which node is shown on click, alongside a `history.pushState` (no Next.js navigation) and `document.title`/meta update. `RoomDetail` reuses the existing `Room` type and `ArrowSliderIcon`/`Picture`/`BigLink`/`RichText`/`SplitWords` primitives; `ImgSlider` is a new Swiper `FreeMode` configuration; `RoomCta` is two static `BigLink`s. Pages compose sections directly by name (no dispatch), content hand-authored verbatim per page from the crawled JSON (including 5 experience-subpage files freshly live-extracted this session, closing the one real content-sourcing gap this rebuild has hit — spec §19.1).

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, GSAP (`ScrollTrigger`, `ScrollToPlugin`, already registered in `lib/gsap.ts`), Swiper (`FreeMode`, `Navigation`, `Keyboard` modules — new to this phase, same package already a dependency), no new npm dependency.

**Spec:** `docs/superpowers/specs/2026-09-04-eriro-clone-design.md` §19 (this phase), §9.15–9.18 (component behavior detail), §4 (route table), §16.3–16.4 (color-swap ruling, direct-composition architecture), §12 (verification).

## Global Constraints

- No `/en/` prefix anywhere — every route/link/test URL is `/experiences/`, `/leiba/`, `/suites/boum/`, etc. (spec §16.1). The raw crawled `mask_pagefilter` hrefs carry a literal `/en/` prefix (e.g. `/en/leiba/`) — strip it during extraction this time (known upfront, not deferred to the final review the way Phase 3's teaserslide `/en/` bug was).
- No generic `SectionRenderer`/`Mask` dispatch — every page composes its section components directly by name (spec §16.4). This phase's `FilterShell` needs each filter item's entire `colPos5` pre-rendered as a single React node; Tasks 7–8 add two small, page-scoped composition files (`ExperienceSubpages.tsx`, `SuiteContents.tsx`) that do the same positional, type-guarded composition every other page.tsx already does — just extracted into named exports so all 6 (or 4) sibling routes can import the same set. This is not a type-driven dispatch: each function handles one specific, known route's fixed section list by name.
- Styling is Tailwind utility classes in JSX. The one exception this phase: `.filter-hover`'s real background rule is a sibling-selector CSS rule (`header:not(.header-menu-open)~div .filterGrid.filter-hover`, confirmed verbatim in `docs/reference/css-clean/pagefilter.css`/`rooms.css`) that reaches across an ancestor's sibling, which Tailwind arbitrary variants can't express cleanly. Add it as one rule appended to the EXISTING `app/globals.css` (not a new CSS file) — same precedent already used there for cascade-layer and color-token rules (spec §16.3's own binding note for this exact rule).
- Content is hand-written TypeScript object literals per page, sourced verbatim (typos included) from the crawled `docs/reference/pages/en__*.json` payloads — never live-fetched, never generated by a script at build/run time (spec §16.2). Extraction scripts in this plan are a one-time authoring aid the implementer runs locally; their output is pasted into the committed `.ts` file.
- `npm run typecheck`, `npm test` (vitest), `npx playwright test`, and `npm run build` must all stay clean after every task. This session's top-level Bash tool is blocked from running `npm run typecheck`/`npx vitest run` directly — route these through a subagent, per this project's own established workaround.
- Image references use the existing `ImageRef` shape (`lib/content.ts`): `src` is `originalUrl` with `/fileadmin/user_upload` replaced by `/images` and percent-encoding decoded; `width`/`height` from `dimensions`; `crop.default`/`crop.mobile` from `crop.default.cropArea`/`crop.mobile.cropArea`; `alt` from `alt` (empty string if `null`); `title` passthrough (`null` allowed); `mime` passthrough. All referenced image files already exist under `public/images/` (Phase 3 confirmed this holds even for image-heavy pages; no reason to expect otherwise here).

## Task 2: Shared header-hover module + FilterShell component

This is the phase's real structural complexity: the GSAP `ScrollTrigger` pin/swap mechanics from spec §9.15, built once as a shared component for both the experiences filter and the suites filter.

**Real DOM/behavior facts confirmed this session** (from the original site's own render function and CSS, `docs/reference/js/js_qcKpu9DE.js` + `docs/reference/css-clean/pagefilter.css`/`rooms.css` — not guessed):
- `filterOuter` wraps BOTH the pinned `filterGrid` bar AND the currently-active item's swapped content as its next sibling (`<div class="filterOuter"><div class="filterGrid grid-container">...filter items...</div>{swapped content}</div>`) — confirmed directly from the crawled bundle's render function. `pin: filterGrid` (only the thin bar pins); `trigger: filterOuter` (whose height, before pinning, is the bar plus whatever content is currently swapped in) with `end: 'bottom top'` — so the pin naturally releases once you scroll past the end of the current item's own content.
- The original's `filterGrid` mouse handlers only force the header's hover background while the bar is actually pinned: `onMouseEnter` sets a shared "force header hover" flag to `true` **only if currently pinned**; `onMouseLeave` always clears it to `false`. The original does this via a global Pinia-style store (`useMenu().toggleHeaderHover`) — i.e. the ORIGINAL site itself uses cross-component shared state for this, not local component state. This project's own `lib/smoother.ts` already has the exact same shape of module (a tiny pub/sub for one piece of imperative cross-component state) — `lib/headerHover.ts` in this task follows that identical pattern.
- `.filter-hover`'s background is `#e4e0db!important` in the raw CSS, but per spec §16.3's explicit binding note for this exact rule, it must use the NEW canvas fill color (`--color-canvas` / `#F2F1EF`) once built — the flat-color swap ruling names this rule specifically as one that was "not yet built... but binding once it is."
- `headerHeight` (from spec §9.15, restated in plain language — authoritative over the raw minified source): `document.querySelector('header .upper').clientHeight - 10` on mobile (`<1024px`), a flat `10` on desktop.
- **This project renders inside GSAP ScrollSmoother** (`components/layout/SmoothScroll.tsx`), created **only at ≥1024px** and killed/recreated on every 1024px crossing; below 1024px the page scrolls natively. Two consequences for `FilterShell`: (a) `ScrollTrigger.create({ pin })` is smoother-aware and works unchanged; (b) spec §9.15's "tween `window` scroll" (`gsap.to(window, { scrollTo })`) **does not move the page when the smoother is active** — the virtualized scroller ignores a raw window scroll. Use `getSmoother()` from `@/lib/smoother` (the same pub/sub `lib/links.ts`'s `jumpToTop()` and `useParallax` use — **never** `window.__scrollSmoother`, which is a test-only hook stripped from production builds): when a smoother exists, tween it (`gsap.to(smoother, { scrollTop: smoother.offset(el, 'top top'), duration: 0.2, ease: 'power1.inOut', overwrite: true })`); otherwise fall back to `gsap.to(window, { duration: 0.2, scrollTo: { y: el.offsetTop }, overwrite: true })`.

```ts
// A tiny pub/sub for one piece of imperative cross-component state: whether
// the header should show its scrolled-state background because the page's
// pinned filter bar (FilterShell) is currently hovered while pinned. Same
// shape as lib/smoother.ts's onSmoother/setSmoother -- Header.tsx owns its
// own local hover state from real mouse events on itself, and ORs it with
// this externally-forced flag, rather than FilterShell reaching into
// Header's own React state directly.
type Cb = (v: boolean) => void;

let current = false;
const subscribers = new Set<Cb>();

export function setHeaderForceHover(v: boolean) {
  current = v;
  subscribers.forEach((cb) => cb(v));
}

export function onHeaderForceHover(cb: Cb) {
  cb(current);
  subscribers.add(cb);
  return () => {
    subscribers.delete(cb);
  };
}
```

export function FilterShell({ id, appearance, variant, items, nodes, activeIndex, metaByIndex }: Props) {
  const [active, setActive] = useState(activeIndex);
  const [isPinned, setIsPinned] = useState(false);
  const filterOuterRef = useRef<HTMLDivElement>(null);
  const filterGridRef = useRef<HTMLDivElement>(null);
  const hasCreatedTrigger = useRef(false);

  const headerHeight = () => {
    if (typeof window === 'undefined') return 10;
    if (window.innerWidth < 1024) {
      const upper = document.querySelector<HTMLElement>('header .upper');
      return (upper?.clientHeight ?? 10) - 10;
    }
    return 10;
  };

  // spec §9.15: ScrollTrigger created 500ms after first content load; on
  // later switches, ScrollTrigger.refresh() after 100ms instead of recreating.
  useGSAP(() => {
    if (!filterOuterRef.current || !filterGridRef.current) return;
    const timer = setTimeout(() => {
      ScrollTrigger.create({
        trigger: filterOuterRef.current!,
        start: `-${headerHeight()} top`,
        end: 'bottom top',
        pin: filterGridRef.current!,
        pinSpacing: false,
        onEnter: () => setIsPinned(true),
        onLeave: () => setIsPinned(false),
        onEnterBack: () => setIsPinned(true),
        onLeaveBack: () => setIsPinned(false),
      });
      hasCreatedTrigger.current = true;
    }, 500);
    return () => clearTimeout(timer);
  }, { scope: filterOuterRef });

  const handleClick = (index: number) => {
    if (index === active) return;
    setActive(index);
    const meta = metaByIndex[index];
    document.title = meta.title;
    document.querySelector('meta[name="description"]')?.setAttribute('content', meta.description);
    window.history.pushState({}, '', items[index].href);
    if (hasCreatedTrigger.current) {
      setTimeout(() => ScrollTrigger.refresh(), 100);
    }
    // spec §9.15: .2s tween to the filter top. Under ScrollSmoother (desktop) a
    // raw window scroll is inert -- drive the smoother; fall back to window when
    // there's no smoother (mobile <1024px, SSR, tests). See Task 2's facts list.
    const el = filterOuterRef.current!;
    const smoother = getSmoother();
    if (smoother) {
      gsap.to(smoother, { scrollTop: smoother.offset(el, 'top top'), duration: 0.2, ease: 'power1.inOut', overwrite: true });
    } else {
      gsap.to(window, { duration: 0.2, scrollTo: { y: el.offsetTop }, overwrite: true });
    }
  };

  const maskType = variant === 'pagefilter' ? 'mask_pagefilter' : 'mask_rooms';
  const maskCls = [appearance.layout, `space-before-${appearance.spaceBefore}`, 'mask', maskType].filter(Boolean).join(' ');
  const filterGridCls = [filterGridBaseCls, isPinned ? 'filter-hover' : '', mobileBlobCls].filter(Boolean).join(' ');

  return (
    <div className={maskCls} {...{ uid: `c${id}` }}>
      <div ref={filterOuterRef} className="filterOuter">
        <div
          ref={filterGridRef}
          className={filterGridCls}
          onMouseEnter={() => { if (isPinned) setHeaderForceHover(true); }}
          onMouseLeave={() => setHeaderForceHover(false)}
        >
          <div className={gridInnerCls}>
            <div className={`${filterWrapperCls} ${mobileTextCls}`}>
              {items.map((item, i) => (
                <div key={item.uid} className={filterItemCls(i === active)} onClick={() => handleClick(i)}>
                  {item.title}
                </div>
              ))}
            </div>
          </div>
        </div>
        {active !== null ? nodes[active] : null}
      </div>
    </div>
  );
}

import json, sys
from urllib.parse import unquote

def image_ref(raw):
    return {
        'src': unquote(raw['originalUrl'].replace('/fileadmin/user_upload', '/images')),
        'width': raw['dimensions']['width'], 'height': raw['dimensions']['height'],
        'mime': raw['mime'], 'title': raw['title'], 'alt': raw['alt'] or '',
        'crop': {'default': raw['crop']['default']['cropArea'], 'mobile': raw['crop']['mobile']['cropArea']},
    }

def ts_str(s):
    return json.dumps(s or '')

def ts_image(img):
    c = img['crop']
    return (f"{{ src: {ts_str(img['src'])}, width: {img['width']}, height: {img['height']}, "
            f"mime: {ts_str(img['mime'])}, title: {json.dumps(img['title'])}, alt: {ts_str(img['alt'])}, "
            f"crop: {{ default: {{ x: {c['default']['x']}, y: {c['default']['y']}, width: {c['default']['width']}, height: {c['default']['height']} }}, "
            f"mobile: {{ x: {c['mobile']['x']}, y: {c['mobile']['y']}, width: {c['mobile']['width']}, height: {c['mobile']['height']} }} }} }}")

    return f"{{ layout: {ts_str(c.get('layout','default'))}, frameClass: {ts_str(c.get('frameClass','default'))}, spaceBefore: {ts_str(c.get('spaceBefore',''))}, spaceAfter: {ts_str(c.get('spaceAfter',''))} }}"

def ts_teaserslide(raw):
    link = raw.get('link')
    link_ts = "''" if not link else (
        f"{{ href: {ts_str(link['href'])}, target: {json.dumps(link.get('target'))}, class: {json.dumps(link.get('class'))}, "
        f"title: {json.dumps(link.get('title'))}, linkText: {ts_str(link.get('linkText',''))}, additionalAttributes: [] }}"
    )
    return (f"{{ uid: {ts_str(raw['uid'])}, title: {ts_str(raw['title'])}, "
            f"imgleft: [{','.join(ts_image(image_ref(i)) for i in raw['imgleft'])}], "
            f"imgright: [{','.join(ts_image(image_ref(i)) for i in raw['imgright'])}], "
            f"infotext: {ts_str(raw.get('infotext',''))}, linktext: {ts_str(raw.get('linktext',''))}, link: {link_ts} }}")

def find(node, id_):
    if isinstance(node, dict):
        if node.get('id') == id_:
            return node
        for v in node.values():
            r = find(v, id_)
            if r is not None: return r
    elif isinstance(node, list):
        for v in node:
            r = find(v, id_)
            if r is not None: return r
    return None

sections = []
def walk(node, in_colpos5=False):

        if 'id' in node and 'appearance' in node and in_colpos5:
            sections.append(node)
        for k, v in node.items():

    elif isinstance(node, list):

walk(d)

    elif s['type'] == 'mask_img':

// tests/e2e/phase4-pages-visual.spec.ts
import { test, expect, type Page } from '@playwright/test';

async function jumpToTop(page: Page) {
  await page.waitForFunction(() => !!window.__scrollSmoother);
  const jump = () => page.evaluate(() => window.__scrollSmoother?.scrollTo('main', false, 'top top'));
  await jump();
  await page.waitForTimeout(300);
  await jump();
  await page.evaluate(() => new Promise((r) => requestAnimationFrame(() => requestAnimationFrame(r))));
}

const routes = [
  { path: '/experiences/', name: 'experiences' },
  { path: '/leiba/', name: 'leiba' },
  { path: '/sela/', name: 'sela' },
  { path: '/herchomen/', name: 'herchomen' },
  { path: '/hantwerc/', name: 'hantwerc' },
  { path: '/sneo/', name: 'sneo' },
  { path: '/suites/boum/', name: 'suites-boum' },
  { path: '/suites/wisa/', name: 'suites-wisa' },
  { path: '/suites/felisa/', name: 'suites-felisa' },
  { path: '/suites/himil/', name: 'suites-himil' },
];
const viewports = [{ width: 1920, height: 951 }, { width: 1440, height: 900 }, { width: 390, height: 844 }];

test.describe('Phase 4 pages visual regression', () => {
  for (const { path, name } of routes) {
    for (const viewport of viewports) {
      test(`${name} matches at ${viewport.width}x${viewport.height}`, async ({ page }) => {
        await page.setViewportSize(viewport);
        await page.goto(path);
        const main = page.locator('main');
        const height = await main.evaluate((el) => el.getBoundingClientRect().height);
        if (height > viewport.height) {
          await page.setViewportSize({ width: viewport.width, height: Math.ceil(height) + 100 });
          await page.waitForTimeout(200);
        }
        if (viewport.width >= 1024) {
          await jumpToTop(page);
        } else {
          await main.scrollIntoViewIfNeeded();
        }
        await page.waitForTimeout(500);
        await expect(main).toHaveScreenshot(`${name}-${viewport.width}.png`, { maxDiffPixels: 50 });
      });
    }
  }
});
